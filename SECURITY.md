# Security Policy

## Reporting a vulnerability

Report potential security vulnerabilities in Controllers privately using the
[NVIDIA Product Security reporting instructions](https://www.nvidia.com/en-us/security/report-vulnerability/).
Use the vulnerability disclosure program linked there, or email
[NVIDIA PSIRT](mailto:psirt@nvidia.com). For email reports, follow the encryption
instructions and use NVIDIA's public PGP key linked on that page.

Do not disclose vulnerability details in public GitHub issues, discussions, or
pull requests.

Include the repository URL, affected version or commit, a description of the
issue and its potential impact, and steps to reproduce it. Include a
proof of concept when available.
